### 镜像构建与导出（供验收复现）

仓库根目录已提供 `Dockerfile`（方案 A 单镜像）。在本机 Docker 环境中：

```bash
# 1) 基于 v0.4.0 标签检出代码后构建镜像
git checkout v0.4.0
docker build -t pingxixi:0.4.0 .
# 2) 导出为 tar 交付文件（无需推送 Docker Hub）
docker save -o "D:\pingxixi-0.4.0.tar" pingxixi:0.4.0
# 3) 导入与运行（验收方）
docker load -i pingxixi-0.4.0.tar
docker run -p 8080:8080 pingxixi:0.4.0
# 访问 http://localhost:8080   （买家端 / 卖家后台 / API 同端口）
```

| 场景 | 操作 | 实测结果 |
| --- | --- | --- |
| 多件合并下单 | 购物车勾选 2 件 → checkout | 生成 1 个订单，`itemCount=2`，金额等于明细之和 |

## 本次交付说明（v0.4.0）

### B.1 订单升级（`4d6085b`）

- 订单五状态：`PLACED`（客户下单，库存已扣减）→ `CONFIRMED`（商家接单）→ `PREPARED`（备货完成）→ `SHIPPED`（开始发货）→ `COMPLETED`（交易完成，累计销量），另有 `CANCELED` 终态（记录取消方与原因，库存回滚）；
- 取消规则：开始发货前（`PLACED` / `CONFIRMED` / `PREPARED`）客户可取消；交易完成前商家可取消；发货后客户取消、完成后商家取消、重复取消均被拒绝；
- 接口：`POST /api/seller/orders/{id}/confirm|prepare|ship|complete|cancel`、`POST /api/customer/orders/{id}/cancel`，共 23 个新增接口；
- 页面：卖家订单管理 `/seller/orders`（列表、状态筛选、五个推进按钮、取消、详情），客户订单 `/customer/orders`（状态筛选、进度条、明细、条件取消）。

### B.2 商品预选升级（`4d6085b`）

- 收藏 `/favorites`：收藏 / 取消收藏 / 是否已收藏 / 收藏列表，`(customerId, productId)` 唯一；
- 购物车 `/cart`：加购、改数量、删除、清空、角标计数；
- 多件合并下单：`POST /api/customer/cart/checkout`，勾选多件生成 1 个订单，明细价格快照、库存扣减、购物车清理同一事务；
- 批量转收藏：`POST /api/customer/cart/to-favorites`。

### 数据模型与规模

- 新增数据表：`mall_order`、`order_item`、`cart_item`、`favorite`；新增枚举 `OrderStatus`；
- 变更规模：33 个文件，+2196 / −28。
