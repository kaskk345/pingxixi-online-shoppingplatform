## 本次交付说明（挑战 A）

### A.1 商品管理升级
- **多商品**：卖家可同时发布多件在售商品，不再受「单品单卖」限制。
- **两级分类**：商品支持一级 + 二级分类选择与筛选，分类树由 `Category` 维护。
- **库存与自动下架**：商品带库存；提交意向即预占 1 件，库存归零自动下架；失败/撤销/作废释放库存并自动恢复在售。
- **浏览 + 搜索**：首页多商品列表（浏览）+ 关键词/一级/二级分类筛选（搜索，`GET /api/products/search`）。
- **多图 + 富媒体**：`images` 多图与详情页轮播；描述按 HTML 富媒体渲染。

### A.2 客户升级
- **自由注册**：用户名、密码、电话、默认交易地点。
- **历史下单**：客户登录后按 `customerId` 查看历史意向/订单。
- **商家客户视图**：卖家查看全部注册客户（不返回密码）及按客户查询购买历史。

### 库存预占（最新提交 `43073a6`）
- 提交意向即预占库存，`SELECT ... FOR UPDATE` 行锁串行化，**防止超卖**；
- 交易成功：本单预占落定，不再重复扣减；其余等候意向作废并释放其预占库存；
- 交易失败 / 买家撤销 / 意向作废 / 卖家下架：释放预占库存；
- 库存归零自动下架；补货/释放后仅对「自动下架」商品自动上架，不误恢复卖家手动下架的商品。

### 已知待完善
- 商品分类目前以名称字符串关联，后续可改为 `categoryId` 外键并补充 `level` 字段；
- 富媒体描述暂无富文本编辑器与 XSS 清洗；
- 客户列表 / 商品搜索 / 订单记录暂无分页。
