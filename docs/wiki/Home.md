## 项目信息

| 项目 | 内容 |
| --- | --- |
| 项目名称 | 在线购物系统（挑战升级） |
| 项目定位 | 小众定制商品的「单品单卖」直销系统 |
| 代码仓库 | <https://github.com/kaskk345/pingxixi-online-shoppingplatform> |
| 开发方式 | Scrum 迭代式增量开发，2 周一个 Sprint |
| 技术栈 | Spring Boot 3 + Spring Data JPA + H2/MySQL；Vue 3 + Vite + Element Plus + Axios |

业务特色：全站在售商品有且仅有一件，卖出后再制作下一件；只有一个卖家；买家无需注册，凭口令码管理自己的购买意向；交易在线下完成；交易前商品冻结，成功则撤下、失败则恢复上线。
