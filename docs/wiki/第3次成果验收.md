### 镜像构建与导出（供验收复现）

仓库根目录已提供 `Dockerfile`（方案 A 单镜像）。在本机 Docker 环境中：

```bash
# 1) 基于 v0.3.0 代码构建镜像
docker build -t pingxixi:0.3.0 .
# 2) 导出为 tar 交付文件（无需推送 Docker Hub）
docker save -o "D:\pingxixi-0.3.0.tar" pingxixi:0.3.0
# 3) 导入与运行（验收方）
docker load -i pingxixi-0.3.0.tar
docker run -p 8080:8080 pingxixi:0.3.0
# 访问 http://localhost:8080   （买家端 / 卖家后台 / API 同端口）
```

## 本次交付说明（v0.3.0）

### 库存预占（`43073a6`，v0.2.0 起）

- 提交意向即预占 1 件库存，`SELECT ... FOR UPDATE` 行锁串行化，**防止超卖**；
- 交易成功：本单预占落定，不再重复扣减；其余等候意向作废并释放其预占库存；
- 交易失败 / 买家撤销 / 意向作废 / 卖家下架：释放预占库存；
- 库存归零自动下架；补货或释放后，仅对「自动下架」商品自动上架，不误恢复卖家手动下架的商品。

### 卖家端商品交易历史（`7c9b48c`）

- 新增 `GET /api/seller/products/{id}/history`，按 `queueTime` 升序返回该商品全部意向（含终态）；
- `SellerIntentView` 共 12 个字段，匿名买家 `customerId` 为空，注册客户额外带用户名，**不返回口令码**；
- 页面 `/seller/products/:id/history`：4 个统计卡片 + 全部 / 进行中 / 已结束三态筛选 + 8 列流水，只读。

### 分类管理（`f348b19`）

- 新增 `PUT /api/seller/categories/{id}`，可改名称与排序，请求体不接受 `parentId`（层级不可改）；
- 校验：分类存在、名称非空、同级不重名；一级分类下仍有子分类时拒绝删除；
- 页面 `/seller/categories`：树形表格，行内可新增子分类、重命名、删除；
- 课程挑战 A.1 第 2 条由「部分满足」转为「满足」。

### 拒绝提示与文档对齐（`51a2169` / `53801c5`）

- 提交意向按商品状态分流提示：已下架 / 已冻结 / 库存不足 / 正常受理；
