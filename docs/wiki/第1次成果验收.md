### 镜像构建与导出（供验收）
仓库根目录已提供 `Dockerfile`（单镜像方案 A）。在本机 Docker 环境中：
```bash
# 1) 构建镜像
docker build -t pingxixi:0.1.0 .
# 2) 导出为 tar 交付文件（无需推送 Docker Hub）
docker save -o "D:\pingxixi-0.1.0.tar" pingxixi:0.1.0
# 3) 运行（本地验证）
docker run -p 8080:8080 pingxixi:0.1.0
# 访问 http://localhost:8080
```
将导出的 `pingxixi-0.1.0.tar`（约 520MB）上传到 GitHub Release 或网盘，并把上表"Docker 镜像"行的地址替换为实际下载链接。
