## 本次交付说明（v0.1.0）

### 基线业务闭环

- **单品单卖**：全站在售商品有且仅有一件，卖出后再制作下一件；
- **单一卖家**：卖家登录后台完成商品维护、意向管理与交易登记，买家侧不设商家概念；
- **买家无需注册**：买家浏览商品后提交购买意向，凭系统下发的口令码查询与管理自己的意向；
- **排队成交**：同一商品的多条意向按提交时间排队，卖家只对队首意向发起交易；
- **交易前冻结**：卖家对某条意向开始交易时，商品进入冻结状态，不再接受新意向；
- **成交撤下 / 失败恢复**：交易成功则商品撤下，交易失败 / 买家撤销 / 意向作废则商品恢复在售；
- **线下交易**：系统只负责意向排队、商品冻结与成交登记，付款与交付在线下完成。

### 已交付范围

- 卖家后台：登录、商品发布与上下架、意向列表、开始交易、登记成交 / 失败；
- 买家端：商品浏览、提交意向、凭口令码查询与撤销意向；
- 交付形态：源码 + Docker 单镜像（方案 A，前端 `dist` 并入后端 jar，同端口 8080）。

### 已知待完善

- 仅支持单件商品，无分类、多图与库存概念（挑战 A 补齐）；
- 买家无账号体系，意向凭口令码管理（挑战 A 补齐客户注册）；
- 无自动化接口断言脚本（后续补 `verify-api-sprint1.ps1` 留存基线口径）。
